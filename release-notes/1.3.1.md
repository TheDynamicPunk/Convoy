### What's new

- **Faster update checks.** Convoy now checks for updates when it opens and every six hours while it's running, instead of once a day. A new **Install updates automatically** switch in Settings → General lets it install them without asking.
- **Clearer browser list.** When several browsers share one setup, Settings → Browser and the first-launch sheet now show each installed browser's icon beside the names.

### Fixed

- **Brave kept asking to finish setup.** Brave reads Chrome's folder for the Convoy connection, so the file Convoy wrote to Brave's own folder was never found. Brave now shares Chrome's file and appears in the same row as Chrome and Arc. If you set Brave up with an earlier version, Convoy moves the file for you the next time it opens.
